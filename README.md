# 상호상회 (Sangho Market) 🍳

주방용품 전문 **미니 쇼핑몰** 데모입니다.
별도의 빌드 도구나 서버 없이 `index.html` 하나만 열면 바로 동작합니다.

🌐 **데모 : https://sanghoy467-cpu.github.io/minishop/**

## 기능

| 기능 | 설명 |
|---|---|
| 🔓 자유 이용 | 로그인 없이 둘러보기 · 찜 · 장바구니 모두 가능 |
| 🧾 회원가입 | 아이디(3자 이상, 중복 확인) · 비밀번호(4자 이상) · 비밀번호 확인 |
| 🔐 로그인 | 가입한 회원만 통과 (체험용 계정 `guest` / `1234`) |
| 🛍 비회원 주문 | 가입 없이 받는 분 · 연락처만 입력하면 주문번호 발급 |
| 🪴 상품 29종 | 주방용품 29개 · 카테고리 7종 · 할인율 18~45% |
| ❤️ 찜하기 | 카드의 하트 버튼으로 찜 · 찜한 상품만 모아보기 |
| 🛒 장바구니 | 수량 조절 · 삭제 · 할인금액/배송비 자동 계산 (5만원 이상 무료배송) |
| 🔍 검색 · 필터 | 상품명/브랜드 검색, 카테고리 필터, 5가지 정렬 |
| 💾 저장 | 회원 · 로그인 · 찜 · 장바구니 · 주문내역 모두 `localStorage` 에 유지 |

## 주문 흐름

```
장바구니 → 주문하기
   ├─ 로그인 상태     → 바로 주문 확정
   └─ 비로그인 상태   → 주문 방식 선택
          ├─ 로그인하고 주문     (로그인 후 주문이 이어서 진행)
          ├─ 회원가입하고 주문   (가입 후 주문이 이어서 진행)
          └─ 비회원으로 주문     (받는 분 · 연락처만 입력)
                                  ↓
                        주문번호 발급 (SH261017-4821 형식)
```

## 실행

```bash
git clone https://github.com/sanghoy467-cpu/minishop.git
cd minishop
start index.html     # Windows
```

또는 `index.html` 파일을 더블클릭하세요.

## 파일 구성

```
minishop/
├─ index.html     마크업 (헤더 · 히어로 · 상품 그리드 · 드로어 · 모달)
├─ styles.css     디자인 시스템 (주방 톤의 구리/크림 팔레트, 반응형)
├─ products.js    상품 데이터 29종
├─ app.js         회원 · 로그인 · 찜 · 장바구니 · 주문 · 검색/정렬 로직
└─ README.md
```
