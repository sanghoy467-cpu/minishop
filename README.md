# 상호상회 — 주방용품 믹서기 🥤

**주방용품 믹서기** 전문 미니 쇼핑몰 데모입니다.
빌드 도구 없는 정적 사이트이며, 회원·주문 데이터는 **Supabase**에 저장됩니다.

🌐 **데모 : https://sanghoy467-cpu.github.io/minishop/**

## 기능

| 기능 | 설명 |
|---|---|
| 🔓 자유 이용 | 로그인 없이 둘러보기 · 찜 · 장바구니 모두 가능 |
| 🧾 회원가입 | 이메일 · 비밀번호(6자 이상) — Supabase Auth 계정 생성, 실패 사유를 한국어로 안내 |
| 🔐 로그인 | 이메일 · 비밀번호로 어느 기기에서나 로그인 |
| 🛍 비회원 주문 | 가입 없이 받는 분 · 연락처만 입력하면 주문번호 발급 |
| 🧾 주문 내역 | 회원은 자기 주문만 조회 (RLS 로 서버에서 강제) |
| 🥤 믹서기 13종 | Supabase `products` 테이블에서 로드 · 카테고리 9종 · 할인율 22~42% |
| ❤️ 찜하기 | 카드의 하트 버튼으로 찜 · 찜한 상품만 모아보기 |
| 🛒 장바구니 | 수량 조절 · 삭제 · 할인금액/배송비 자동 계산 (5만원 이상 무료배송) |
| 🔍 검색 · 필터 | 상품명/브랜드 검색, 카테고리 필터, 5가지 정렬 |
| 💾 저장 | 회원·주문은 Supabase, 찜·장바구니는 `localStorage` |

## 주문 흐름

```
장바구니 → 주문하기
   ├─ 로그인 상태     → 바로 주문 확정
   └─ 비로그인 상태   → 주문 방식 선택
          ├─ 로그인하고 주문     (로그인 후 주문이 이어서 진행)
          ├─ 회원가입하고 주문   (가입 후 주문이 이어서 진행)
          └─ 비회원으로 주문     (받는 분 · 연락처만 입력)
                                  ↓
                        주문번호 발급 (SH261017-4821 형식)
```

## 실행

```bash
git clone https://github.com/sanghoy467-cpu/minishop.git
cd minishop
start index.html     # Windows
```

또는 `index.html` 파일을 더블클릭하세요.

## 파일 구성

```
minishop/
├─ index.html           마크업 (헤더 · 히어로 · 상품 그리드 · 드로어 · 모달)
├─ styles.css           디자인 시스템 (민트 바탕 + 구리 포인트, 반응형)
├─ products.js          믹서기 13종 예비 데이터 (DB 연결 실패 시에만 사용)
├─ supabase.js          Supabase 연동 계층 (인증 · 상품 · 주문)

├─ supabase/schema.sql  테이블 · RLS 정책 · 상품 시드
└─ README.md
```

## Supabase

인증과 데이터는 Supabase 가 담당합니다.

| 테이블 | 읽기 | 쓰기 |
|---|---|---|
| `products` | 누구나 | 불가 (익명 키로 수정·삭제 불가) |
| `orders` | 로그인한 본인 주문만 | 누구나 생성 (비회원 주문 허용) |

RLS 정책이 서버에서 강제하므로, 브라우저 코드를 조작해도
남의 주문을 읽거나 상품 가격을 바꿀 수 없습니다.

**스키마 적용** — Supabase 대시보드 → SQL Editor 에
[`supabase/schema.sql`](supabase/schema.sql) 전체를 붙여넣고 Run.
여러 번 실행해도 안전합니다.

**설정값** — `supabase.js` 상단의 URL 과 publishable(anon) 키는
브라우저에 공개되어도 안전하도록 설계된 값입니다.
반대로 **secret 키, access token(`sbp_…`), DB 직결 문자열
(`postgresql://…`)은 절대 저장소에 넣지 마세요.** 정적 사이트의
모든 코드는 방문자에게 그대로 노출됩니다.

> 가입은 이메일 + 비밀번호로 합니다. 이 프로젝트는 이메일 자동 확인
> (mailer_autoconfirm)이 켜져 있어 가입 즉시 로그인됩니다. 확인 메일 설정을
> 켜면 `supabase.js` 가 세션 없는 응답을 감지해 "인증 메일을 보냈습니다"
> 화면으로 자동 전환합니다.
